A

Bienvenido a A51

Setup en 15 minutos. Seguí los pasos en orden.

1

Mandame estos datos por WhatsApp

Te invito a todo desde mi lado.
  • GitHub tu usuario de GitHub (ej: juanperez)
  • Vercel el email con el que vas a usar Vercel (creá cuenta gratis en vercel.com si no tenés)
De mi lado: te agrego como collaborator al repo de GitHub y al team de Vercel. Vas a recibir 2 mails de invitación. Aceptalos.
2

Instalá lo necesario

Una sola vez en tu compu. ~5 min.

Node.js 20+ → nodejs.org (instalador, siguiente siguiente)

Git → git-scm.com (si no lo tenés)

VS Code o Cursor → tu editor

Claude Code → claude.com/claude-code

Después abrís terminal y corrés:

# Verificar que Node está OK
node --version  # tiene que decir v20 o más

# Instalar Vercel CLI global
npm i -g vercel
3

Clonar el proyecto

Bajás el código a tu compu.
# En la carpeta donde guardás tus proyectos
git clone https://github.com/cotte4/A51BARBERSHOP.git
cd A51BARBERSHOP/a51-barber

# Instalar dependencias
npm install
4

Bajar las claves (env vars)

No te mando nada por chat. Las bajás solo desde Vercel.
# Login a Vercel (te abre el navegador)
vercel login

# Conectar esta carpeta al proyecto
vercel link
# > Seleccioná el team de Was
# > Seleccioná el proyecto "a51-barber"

# Bajar todas las claves a .env.local
vercel env pull .env.local
Importante: .env.local tiene secretos. Nunca lo subas a GitHub, no lo compartas por chat, no lo mandes por mail. Solo vive en tu compu.
5

Levantar la app

localhost en tu navegador.
npm run dev

Abrí http://localhost:3000 y ya tenés la app corriendo contra una base de datos de pruebas (no toca producción).

Listo: ya podés tocar código y ver los cambios en vivo. La DB es una rama de Neon dedicada para vos — rompé lo que quieras, no afecta la app real.
6

Tu primer cambio

El flujo que vamos a usar siempre.
# Crear branch propia (NUNCA tocar master directo)
git checkout -b ui/tu-primer-cambio

# ... tocás código con Claude Code ...

# Subir cambios
git add .
git commit -m "ui: descripción corta"
git push -u origin ui/tu-primer-cambio
Magia: apenas pusheás, Vercel te genera un preview URL automático (algo como a51-git-ui-xxx.vercel.app). Me lo pasás, lo veo en el celular, te doy feedback. Cuando está OK, lo mergeo a producción.
7

Antes de tocar cualquier cosa, leé

3 archivos. Está todo ahí.
  • → CLAUDE.md (raíz) — design system completo: colores, clases CSS, do's and don'ts
  • → a51-barber/docs/feature-map-ux.md — inventario de las 22 pantallas que existen
  • → a51-barber/docs/design-handoff-progress.md — el tablero por dónde vamos
Reglas clave: tema dark con accent verde neón #8cff59. Nunca bg-white ni text-gray-*. Mobile-first. Una branch = una pantalla.

¿Trabado en algún paso?

Mandame WhatsApp con un screenshot del error y lo destrabamos en 5 min.
